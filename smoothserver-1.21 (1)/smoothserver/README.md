# Smooth Server (Fabric, Minecraft 1.21)
Server-side only. Build: install JDK 21, then `gradle build` (or copy these files into the
official Fabric example mod, which includes the Gradle wrapper -> `./gradlew build`).
Jar appears in build/libs/smoothserver-1.0.0.jar. Put it in the server's mods folder with Fabric API.
Tune the constants at the top of SmoothServer.java.
